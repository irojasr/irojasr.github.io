📐 Mathematical Rules, Edge Cases & Conventions
  • Update Rule: If a cell has value \(k\), and an adjacent orthogonal neighbor has value exactly \(k+1\), the neighbor becomes \(k\). (Equivalently, a cell in state \(v\) converts to \(v-1\) if at least one orthogonal neighbor has value \(v-1\)).
  • Simultaneous Execution: Transitions are strictly synchronous (\(A^{(t)} \mapsto A^{(t+1)}\)) using double buffering. Scan order does not affect dynamics.
  • Conflict Freeness: Because each cell \(v\) only ever converts to its unique predecessor \(\text{pred}(v)\), competing updates to the same cell always assign the identical value. Conflicts are mathematically impossible.
  • Cyclic vs. Linear Succession: In cyclic mode (\(\mathbb{Z}_K\)), the maximum state \(K\) wraps to \(1\), meaning \(K\) converts an adjacent \(1\) into \(K\). In linear mode, \(1\) cannot be converted and \(K\) cannot convert anything.
  • Boundary Topologies: In periodic mode, coordinates wrap toroidally modulo \(m\) and \(n\). In degenerate grids (\(1 \times n\), \(m \times 1\), \(1 \times 1\)), self-neighbors are strictly excluded.
  • The \(1 \times n\) Permutation Theorem: Under periodic boundaries with cycle modulus \(K = n\), the configuration \((1, 2, \dots, n)\) undergoes a cyclic right-shift at every step: \(A^{(t+1)}_i = A^{(t)}_{(i-1)\bmod n}\).
